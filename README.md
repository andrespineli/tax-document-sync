# Sincronizador de Documentos Fiscais

Desktop app for local Brazilian fiscal document synchronization.

## Development

```sh
npm install
npm run dev
```

Quality gate:

```sh
npm run check:licenses
npm run lint
npm run typecheck
npm test
npm run build
```

## Distribution

The app is packaged with `electron-builder` and updates are handled by
`electron-updater` from GitHub Releases.

Local package smoke test:

```sh
npm run pack
```

Release builds are generated by publishing a GitHub Release with a tag matching
`package.json`, for example `v0.1.0`.
